# Security Policy

FinReconLab is not production-ready. The repository currently contains a narrow deterministic reconciliation experiment and should not be used to process real financial, personal, merchant, customer, or production data.

## Reporting Security Issues

Please report suspected security issues responsibly. Do not open a public issue containing secrets, credentials, real financial records, personal data, production logs, or exploit details that could put users or systems at risk.

Until a dedicated private security contact is published, open a public issue only with a minimal, non-sensitive summary requesting a private reporting path.

## Data Handling

Do not submit real financial or personal data in issues, discussions, pull requests, examples, tests, benchmark inputs, or documentation. All project examples and future datasets must be synthetic.
